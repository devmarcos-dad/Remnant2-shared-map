# MapSync LAN — pacote zero-config

Para o jogador: use **`drop-in/MapSync-LAN/`** (leia o `LEIA-ME.txt`).

## Instalar

1. Copie `drop-in/MapSync-LAN/MapSync` → `ue4ss\Mods\`
2. `mods.txt`: `MapSync : 1`
3. Backup `Desktop\Remnant2-SaveBackup-*`
4. Coop (mesma rede) → **F7** → explore / **F10**

`lan_bridge.exe` sobe sozinho. Firewall: permita em rede privada se pedir.

Para remoto use o pacote Steam: [`STEAM.md`](STEAM.md) / `drop-in/MapSync-Steam/`.
